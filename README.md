# 澳股市场雷达 · ASX Market Radar

澳洲股市走势概率预测 + 板块资金流 / 热炒温度 / 做空压力归因 + 具体的做多做空名单。
一个按钮更新全部指标，并自动生成可放进云盘的单文件报告。

```bash
pip install -r requirements.txt
python run.py
```

Windows 上也可以直接双击 **`启动.bat`**（会自动检查并安装依赖）。
浏览器打开 `http://127.0.0.1:8849`。首次运行需下载 12 年行情与 5 年 ASIC 空头数据并训练模型
（约 2–3 分钟），之后每次点「更新全部指标」约 **数秒**。

```bash
python run.py --cli       # 只在终端打印报告
python run.py --export    # 只生成云盘单文件后退出
python run.py --refresh   # 丢弃缓存，强制重下重训
python run.py --port 9000
```

## 顶部资金流面板（v2 新增）

打开就是最上方那两栏：**钱正在进哪个板块的哪几只股票 / 正在从哪撤**。
每只股票都写明触发原因和具体数字（净买卖盘金额、被做空规模及其20天变化、成交异动）。

**这是对"现在"的测量，不是对"未来"的预测。** 这个区分是实测出来的，不是谨慎措辞：

| 检验 | 结果 | 结论 |
|---|---|---|
| 板块空头变化 → 未来板块超额收益 | 相关峰值在 **lag +4 周** | ❌ 板块层面**落后**于价格，无领先性 |
| 个股看空评分 → 未来个股相对收益 | 修正后 IC **t = −2.20**（未修正 −7.24） | ⚠️ 勉强达标（边缘显著） |
| S4 吸筹结构 → 60日超额 | 修正后 **t = +1.07**（未修正 +5.43） | ❌ **未通过，已撤销权重** |

> **2026-08-24 重要更正**：以上 t 值现在都做了**重叠样本修正**。
> 本系统每个交易日都算一次「未来 20/60 天收益」，相邻观测的窗口几乎完全重合
> （实测 IC 序列 lag-1 自相关 +0.90），把它当独立样本会让 t 值**虚高 3–5 倍**。
> `validate.py` 的文档一直写着用 Newey-West，但代码里之前是朴素 t 值——已修复。
> 受影响最大的是 S4：它当年凭 t=6.93 拿到了权重，修正后只有 +1.07，**权重已按项目自己的规矩撤销**。

所以：**板块排序看"现在钱在哪"；个股看空名单是全系统证据最强的部分，但也只是勉强达标。**

## 按两份规格增强的内容（v2）

依据 `asx-smart-money-detector-spec.md` 与 `asx-sector-flow-tracker-spec.md`。
规格里自带的"判决点"我**真的跑了**，没有假设通过：

**已实现并通过检验**
- **S4 吸筹型价量结构** — 严格按规格写法：四项**先取对数再相加、各自独立截尾**，
  不用规格明确警告过的四项连乘（方差爆炸且 Amihud→0 时发散）。
  ⚠️ 但它**没有通过判决点**：当年记录的 t=6.93 未做重叠修正，修正后仅 +1.07（生产用的
  滚动 z 形式更低，+0.45），已**撤销其在资金面板排序里的权重**，只作为卡片上的描述保留
- **S2 / F2 空头持仓** — ASIC 每日申报，1,168 天 × 2,591 只
- **S5 板块相对强度** — 已有
- **顶部资金流入/流出面板** — 新增，见上

**已实现但明确不参与打分**
- **S1 / F1 机构举牌（Form 603/604/605）+ S3 董事增减持（Appendix 3Y）**

  ASX 的公开接口**每家公司只返回最近 5 条公告**（`count=200`、`pageSize`、`startDate`
  四种参数都试过，全部返回 5 条），**无法回溯历史**。而规格 2 第 5 节把
  「F1 滞后相关峰值必须在 lag < 0」列为整个数据源的生死判决点——没有历史，这个检验**跑不了**。

  所以系统**从今天起每天自动采集存档**（含 PDF 解析、剔除 Vanguard/BlackRock 等被动持仓、
  剔除证券借贷产生的名义持仓），界面显示「已收 N 条 · 采集 M 天」，但 `scored=False`。
  等积累 1–3 个月够做检验了，通过才纳入评分。首次采集已入库 152 条。

**明确不做**
- **ASX 期权流** — 规格 0.5 说明 ASX 个股期权流动性极低，除 ASX 20 外无有效信号，不浪费工作量
- **板块 ETF 申赎** — 规格 2 第 0 节：11 个板块只有 4 个有本土 ETF，且最想要的医疗保健恰恰没有。
  全球 ETF（DRUG/IXJ/FUEL）是 "Global ex-Australia"，用它推断澳洲资金流是错的

## 结论长什么样

界面第一屏就是结论：两张卡片，一边做多一边做空，各三只股票，
每只都列出**触发它的具体数字**（空头持仓变动、资金流、技术位置、回补天数、
日均成交额、建议止损位），以及这套评分**在过去 4.6 年的实测表现**。

关键是：**两侧的证据强度完全不同，界面上直接标出来。**

| | 横截面 IC | t 值（重叠修正后） | 未修正的 t | 判定 |
|---|---|---|---|---|
| 做空评分 | −0.0332 | **−2.20** | −7.24 | 勉强达标（负号即为正确方向） |
| 做多评分 | +0.0060 | +0.31 | +1.07 | 不显著 |

做空评分的最高分组未来 20 日回报 +0.44%，最低分组 +1.38%，价差 **−0.95%/20日（约 −12%/年）**。

**但有一个必须理解的区别**：样本期内这个空头篮子本身仍然**上涨** +2.15%/年
（等权市场 +12.67%）。它可靠的是**跑输**，不是**下跌**。
直接裸空还需要你对大盘方向另有把握；更稳妥的用法是低配，或与多头配对成对冲。

还有一条实测出来的纪律：**空头信号衰减很快。**

| 再平衡周期 | 空头篮子相对市场 |
|---|---|
| 20 日 | **−10.5%/年** |
| 40 日 | −6.5%/年 |
| 60 日 | +1.9%/年（信号消失） |
| 120 日 | +5.1%/年（反转，轧空） |

**名单大约每月刷新一次；拿满一个季度历史上会反转。**

## 四个分数，回答四个不同的问题

把它们混成一个「板块评分」是大多数轮动看板没用的原因。

| 分数 | 回答 | 构成 |
|---|---|---|
| **资金** | 钱在进还是在出 | 蔡金资金流、主动买盘、OBV 斜率、成交额、RS 相对强度、RS 动量、空头回补 |
| **热度** | 是否正在被炒作 | 成交额异动、价格加速、波动扩张、超买占比、近 52 周高点占比、振幅 |
| **延展度** | 价格已经走了多远 | 52 周位置、距 200 日均线、RSI |
| **做空压力** | 空头在哪里聚集与建仓 | 空头水平、**空头 20 日增仓**、资金流出、广度恶化、RS 破位、超涨 |

热度不等于资金——一个板块完全可以在高换手中被派发。

### 「有迹象流入」和「已经大幅流入」怎么分

用**资金 × 延展度**的二维图（界面上有）：

- **右下 · 资金迹象流入（早期）** — 钱刚进来，价格还没走远。风险回报最好的做多位置
- **右上 · 资金已大幅流入（拥挤）** — 钱到位了，价格也高了。动能还在，但追高要更严的止损
- **左上 · 涨高但资金流出（派发）** — 价格仍在高位而资金在撤。**做空的首选背景**
- **左下 · 跌深且资金流出（超跌）** — 下跌动能仍在，抄底缺乏资金面依据

## 空头数据：这是澳洲市场独有的优势

澳洲**强制每日申报空头仓位**，ASIC 公开发布。所以这里的持仓是**真实披露的机构仓位，不是推断**。

- 来源：`download.asic.gov.au/short-selling/RR{YYYYMMDD}-001-SSDailyYTD.csv`
- 覆盖：**1,168 个交易日 × 2,591 只股票**（2022-01 至今），5 次请求、约 6 秒下载完
- ASIC 按 **T+4 个营业日**发布，系统已把每条数据对齐到**它实际公开的那一天**，
  避免回测时使用当时还看不到的信息

最有价值的一列是 **Δ20日**：空头正在**新建**仓位，比空头已经很高更有信息量
（Boehmer, Jones & Zhang 2008；Asquith, Pathak & Ritter 2005）。
系统同时给出**回补天数**（空头股数 ÷ 20 日均量）用于评估轧空风险。

## 大盘方向：实测几乎不可预测

| 预测目标 | 样本外 AUC | Brier 技能分 | 判定 |
|---|---|---|---|
| 未来 20 日波动率上升 | **0.717** | **+0.143** | 显著预测力 |
| 未来 1 日方向 | 0.565 | +0.009 | 中等 |
| 未来 5 / 10 / 20 日方向 | 0.45–0.51 | 负 | **无统计显著预测力** |

最终概率 = 基准率 + λ ×（模型概率 − 基准率），λ 由实测 AUC 决定。
**AUC ≤ 0.5 时 λ=0，界面直接显示历史基准率并标注「无统计显著预测力」**。

## 建模纪律

- 全部为**样本外**：扩张窗口每 21 个交易日重训，只能看到预测日之前的数据
- **净化与禁运**：h 日前瞻标签会泄漏 h 日未来信息，训练集截止到 t−h−5（López de Prado 2018）
- **三模型等权组合**：L2 逻辑回归 + 梯度提升树 + 43 个单因子预测的均值组合
  （Rapach, Strauss & Zhou 2010）
- **滚动 Platt 校准**：原始模型普遍「有区分度但过度自信」（AUC>0.5 而 BSS<0）
- 选股评分用**横截面 IC、五分位价差、多空组合**三种口径交叉验证，而不是只看一条净值曲线

## 已知局限（请务必读）

- **做多评分未通过显著性检验**。做多篮子年化 +13.37% vs 等权市场 +12.67%，
  超额接近零且波动更高（夏普 0.56 vs 0.82）。三只名单更适合作为选股起点，不是照单执行
- **所有 t 值都必须做重叠样本修正**。前瞻收益按日重算但窗口重叠，朴素 t 值虚高 3–5 倍。
  报告里 `t_stat` 已是 Newey-West 修正值，`t_naive` 仅供对照。**看到两位数的 t 值先怀疑没修正**
- **做空评分只是边缘显著**（修正后 t=−2.20），且**衡量「跑输」而非「下跌」**，裸空需要额外的大盘方向判断
- **市场中性多空扣成本后年化仅 +0.60%、夏普 0.04**——一年换 39 批仓，换手成本吃掉了大部分毛收益。
  **这个信号的正确用途是「回避 / 少配」，不是「靠做空赚钱」**
- **成本地图（成交量分布）只是测量，不参与任何评分**：上方套牢盘占比未修正时 t=+7.67，
  修正后仅 +1.58，没有可用的预测证据
- **澳洲不公开做空者身份**。ASIC 的文件是全市场汇总（只有股数与占比），没有持有人名称，
  也没有成交价。欧盟/英国会公布 0.5% 以上的空头持有人姓名，澳洲不会。
  「空头成本」一栏是**全体空头的平均建仓价估算**，不是某一家机构的仓位，
  且其中一部分（2022年前的老仓）永远无法定价——表里的「可追溯」列就是这个比例
- **更快的空头数据拿不到**：ASX 每日毛空头卖出（T+1）已移入 ASX Online 参与者门户，需券商账号；
  Cboe（现 TMX Australia）那份只覆盖其独有产品，与本股票池零重叠。
  免费可自动化的只有 ASIC 的 T+4 存量数据
- 板块成分为静态名单，存在幸存者偏差。已退市标的（JHG、NSR、SVW）已剔除
- 未纳入基本面（估值、盈利修正）、期权隐含波动率曲面、**融券成本与可借额度**。
  实际做空还需确认券源与融券费率
- 回测未考虑冲击成本、融资成本与税负

### 一个会改变结论的数据陷阱（如果你要改代码，请勿改回去）

澳股股息率 4–6% 且集中在两次派发，**未复权价会在每个除息日出现假跌**。
实测 14% 的股票 60 日收益率偏差超过 1pp，最大 8.59pp——而且受影响最重的正是
银行与 REITs，也就是最容易被误判为「资金流出/做空目标」的板块。
实测例子：GPT 60 日收益从 −2.07%（未复权）变成 +0.32%（复权），**符号反转**。

所以系统里所有**跨日**的价格指标（收益率、均线距离、RSI、52 周位置、广度）
一律使用复权价；只有**日内**指标（蔡金资金流、MFI、ATR、成交额）使用原始 OHLC，
因为它们在单日内部是自洽的。
